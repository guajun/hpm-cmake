02

Commit source, Presets and lock. In every new clone, rerun the same installer to rebuild .hpm/ without reimporting the board or upgrading dependencies.

03

Activate and build

.\.hpm\activate.ps1
cmake --preset default

Only this shell is affected. Activation scripts are generated locally and are not committed.

The lock pins the SDK commit, wrapper release, Windows/Linux GCC archives and SHA-256 values, plus Python package versions and wheel hashes. Reinstalling restores the lock; it never silently updates it.

Linux requires host Python 3.10–3.14 with venv. Windows prepares a private interpreter. Linux host Python patch versions are not pinned.

Parameter rules and examples

Project defaults to the current folder. BuildDirectory is relative to Project. SDK/GCC paths point to roots containing cmake/ or bin/. SdkRevision is needed only for SDK archives without Git metadata. Existing locks do not need BuildDirectory; missing dependencies are downloaded from the lock.

PowerShell uses -NonInteractive; Bash uses --non-interactive. Missing inputs fail without waiting. Version defaults to the project's pinned release; an explicit conflict is rejected.

Focused on firmware builds.

Official tools initialize projects. This repository contains no example firmware or probe/debug scripts. Initial import and clone restoration are tested on Windows and Ubuntu.
