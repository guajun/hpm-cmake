Run the one-line command to generate .hpm/ and personal Presets. Every output stays local. On another machine, prepare the official environment and rerun the installer.

03

Activate and build

.\.hpm\activate.ps1
cmake --preset hpm
cmake --build --preset hpm --parallel

Only this shell is affected. Activation scripts are generated locally and are not committed.

Parameter rules and examples

Project defaults to the current folder. BuildDirectory is relative to Project. SDK/GCC paths point to roots containing cmake/ or bin/. PythonExecutable points to an existing SDK Python. All tools are provided by the maintainer; this installer never downloads them.

PowerShell uses -NonInteractive; Bash uses --non-interactive. Missing inputs fail without waiting. Version selects only this wrapper release, defaulting to latest; it does not manage SDK/compiler versions.

Focused on firmware builds.

Official tools initialize projects. This repository contains no example firmware or probe/debug scripts. Local integration and firmware builds are tested on Windows and Ubuntu.
