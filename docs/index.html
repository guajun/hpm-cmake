Parameter rules and examples

Project defaults to the current directory, which can be empty. SdkEnvRoot optionally selects an official environment bundle. SDK/GCC paths point to roots containing cmake/ or bin/. PythonExecutable points to an existing SDK Python. All tools are provided by the maintainer; this installer never downloads them.

PowerShell uses -NonInteractive; Bash uses --non-interactive. Missing inputs fail without waiting. Version selects only this wrapper release, defaulting to latest; it does not manage SDK/compiler versions.

Focused on shell activation.

Official tools initialize projects. This repository contains no example firmware or probe/debug scripts. Activation, command selection and restoration are tested on Windows and Linux.
