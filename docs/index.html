THREE STEPS

From official project to everyday builds.

01

Generate with HPMicro

Use start_gui or generate_project to choose your board, application and build type. Keep the source folder outside the SDK.

Official SDK environment ↗
02

Run the installer

The release is downloaded and checked. Your existing CMake files, application source and BSP are preserved. SDK and GCC paths are bound to this project; its private Python is prepared automatically.

03

Activate and build

.\activate.ps1
cmake --preset default
cmake --build --preset default --parallel

Activate each new terminal. Settings affect only this terminal. Use .\activate.ps1 -Deactivate to restore its previous environment.

PARAMETER REFERENCE

The same interface for people and agents.

Explicit paths win. Otherwise, the installer checks the official build cache, environment variables and known defaults. Interactive mode asks only when information is missing or ambiguous.

ParameterFormat / exampleMeaning & default
-Project'.' / 'C:\firmware\my-app'Application source folder. Default: current folder.
-BuildDirectory'hpm6e00evk_build'Original CMakeCache folder, relative to Project. Auto-select only if exactly one build matches.
-SdkEnvRoot'C:\HPMicro\sdk_env'Optional official environment root for SDK, GCC and generator commands.
-SdkRoot'C:\HPMicro\sdk_env\hpm_sdk'Explicit SDK root; otherwise build cache, HPM_SDK_BASE or defaults.
-ToolchainRoot'C:\tools\hpm-gcc'Explicit compiler root; otherwise cache, GNURISCV_TOOLCHAIN_PATH or compiler on PATH.
-SdkRevision'v1.12.1' / full commitRequired only for an SDK archive without Git metadata.
-Version'latest' / 'v0.2.0'Release to install. Default: latest.
-Language'en' / 'zh'Setup prompt language. Default: en.
-NonInteractiveswitchNever prompt. Missing or ambiguous values fail with the parameter name.
Full non-interactive example
& ([scriptblock]::Create((irm https://github.com/guajun/hpm-cmake/releases/latest/download/install.ps1))) -Project 'C:\firmware\my-app' -BuildDirectory 'hpm6e00evk_build' -SdkRoot 'C:\HPMicro\sdk_env\hpm_sdk' -ToolchainRoot 'C:\HPMicro\sdk_env\toolchains\rv32imac_zicsr_zifencei_multilib_b_ext-win' -SdkRevision 'v1.12.1' -Version 'v0.2.0' -Language en -NonInteractive

Example paths only: replace them with your actual installations. Run from a PowerShell terminal; -NonInteractive is an installer switch.

Project local, from install to activation.

The installed activate.ps1 is part of your project. Machine-specific bindings live in ignored .hpm/local.json. SDK and GCC are reused through local directory links; no user or system environment variables are written.

Your original board and build mode remain authoritative. A new machine can run the project's sync.ps1 to prepare the locked dependencies. The importer does not create BSPs or choose a board for you.
