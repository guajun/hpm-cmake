HPMICRO · NATIVE CMAKE

官方工程。
项目自己的构建环境。

用 HPM 官方生成器选择板卡与应用，再接入固定版本的 SDK、GCC 和私有 Python。日常直接运行 CMake，环境随命令生效。

完整使用说明 · 下载官方生成器

生成 → 接入 → 开发

01 / 官方生成

在 start_gui 或 generate_project 中选择板卡、应用和构建类型，生成 CMake 构建目录。

02 / 导入配置

读取 CMakeCache，添加项目环境和 Presets。保留应用 CMakeLists、源码及 BSP。

03 / 原生构建

同步锁定依赖，在项目内构建。板卡配置继续来自厂商 SDK 或你自己的 BSP。

从 clone 接入

git clone https://github.com/guajun/hpm-cmake.git C:\tools\hpm-cmake
& C:\tools\hpm-cmake\hpm-cmake.ps1 import `
    -Project C:\firmware\my-app `
    -BuildDirectory C:\firmware\my-app\hpm6e00evk_build

路径和板名是示例。Project 指向应用源码目录，BuildDirectory 指向官方工具生成的构建目录。

直接使用 release

& ([scriptblock]::Create((irm https://github.com/guajun/hpm-cmake/releases/latest/download/install.ps1))) `
    -Project C:\firmware\my-app `
    -BuildDirectory C:\firmware\my-app\hpm6e00evk_build

可加 -Version v0.1.0 固定封装版本。安装器在工程内暂存归档、校验 SHA-256 并完成接入，不安装全局命令。

SDK ZIP 没有 Git 信息时，补充 -SdkRevision 指定其真实官方 release tag 或 commit。已有 Presets 或导入文件不会被自动覆盖。

接入后

.\.hpm-cmake\sync.ps1
.\.hpm-cmake\doctor.ps1
cmake --preset default
cmake --build --preset default --parallel

default 沿用官方选择的构建组合。依赖位于 .hpm/，可提交的环境脚本位于 .hpm-cmake/。无需 uv，也不修改用户或系统环境变量。

支持范围

当前支持 Windows x64、PowerShell 5.1+、HPM 官方 GCC 13.2.0；需要已有 Git、CMake 3.24+ 和 Ninja。已验证 HPM6E00EVK blink，HPM6750EVKMINI 用于额外构建验证。其他工具链版本会明确报错。

项目初始化与 BSP 由官方工具负责。hpm-cmake 负责环境接入和构建兼容；物理探针、烧录与调试单独管理。
